    필터

    좌측 필터는 모든 섹션에 공통 적용됩니다. 국가·플랫폼·사용기간은 여러 개를 동시에 선택할 수 있고, 상단 칩의 × 로 하나씩 해제합니다.

    1일당 가격

    JPY 가격을 환율로 KRW 환산한 뒤 사용기간(일)으로 나눈 값입니다. 사용기간을 알 수 없는 상품은 1일당 비교에서 제외됩니다.

    현재 대시보드 대비 변경점

    1. 화면 구조

    상단 히어로 + 칩 필터 + 가로 확장 필터 9개가 본문을 밀어냄
    슬림 상단 바 + 좌측 고정 필터 사이드바 (스크롤해도 필터 유지)

    2. 핵심 요약

    KPI 카드 5개(상품 수·평균·최저·Local·5G)가 같은 비중
    “지금 가장 싼 상품”을 큰 카드로, 국가별 최저 1일가·변동률 카드로 분리 (카드 클릭 = 국가 필터)

    3. 신규 시각화

    수집 이력이 있음에도 시점 비교 화면 없음
    가격 추이(수집 시점별 중앙가) · 플랫폼 경쟁력 · Local vs Roaming 프리미엄 · 망 세대 누적 막대

    4. 히트맵

    전체 셀 기준 8단계 색 (기간이 길면 항상 싸 보임)
    같은 기간 열 안에서 색 비교 + 최저가 점 + 보유 플랫폼 표시 + 클릭 필터

    5. 표

    17열 단일 표, 가로 스크롤 심함
    가성비 Top 10과 상세 목록 분리, 배지(네트워크·망 세대) 적용, 접기/펼치기
